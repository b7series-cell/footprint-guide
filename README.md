# Footprint bot guide

An illustrated guide to a personal order-flow alert bot: how it reads 1-minute footprint bars, the three setups it alerts on (stacked imbalance, absorption, delta divergence), how trades are managed, its risk rules, daily routine, dashboard and alarms.

View it at https://b7series-cell.github.io/footprint-guide/

The page is a single self-contained `index.html` (no external scripts). Charts are drawn examples, not real trades. It describes rules for testing and isn't a recommendation to trade.
